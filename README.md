# Hi, I'm Murat Sivil 👋

I'm a **.NET / Backend Developer** from Turkey with a B.Sc. in Computer Engineering. I focus on building backend-heavy systems with **ASP.NET Core, Clean Architecture, CQRS/MediatR, REST APIs, SQL, Redis, Docker, and B2B integrations**.

My work has mostly been around **flight API integrations, real-time payment engines, reservation systems, and industrial management platforms**. I care about clean boundaries, maintainable architecture, reliable integrations, and practical business workflows.
